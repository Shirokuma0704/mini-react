타이머 useEffect · 치우는 함수 · 지켜볼 값 · 명세 4-5

  • 1초마다 오르는 숫자: useEffect(() => { setInterval(…); return () => clearInterval(…) }, [running])
  • 다른 상태 바꾸기: 다시 그려도 [running]이 그대로면 타이머는 새로 안 생겨요
  • 멈춤 / 다시 시작: running이 바뀌면 치우는 함수 → 다시 실행
  • 목록 없는 effect가 patch 다음에 본 숫자도 아래에 적혀요

거르기 useMemo · 지켜볼 값 · 명세 4-6

  • 보이는 목록: useMemo(() => 거르기(nums), [nums, onlyEven])
  • 짝수만 / 전부 보기: onlyEven이 바뀜 → 다시 계산
  • 다른 상태 바꾸기: 다시 그려도 지켜볼 값이 그대로면 계산 안 함
  • 새 배열로 추가 vs push로 추가: push 뒤에 다른 상태를 바꿔 보세요
