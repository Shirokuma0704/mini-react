  • 함수로 두 번: setCount(c => c + 1)를 두 번
  • 값으로 두 번: setCount(count + 1)를 두 번
  • 같은 값: setCount(count)
  • 타이머로 두 번: 0.3초 뒤 타이머 안에서 setCount(c => c + 1)를 두 번 (이벤트 밖)
